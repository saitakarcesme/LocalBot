# Security

LocalBot can read and modify project files, invoke configured tools, and expose an interactive terminal to paired devices. Treat pairing codes and model credentials as secrets.

- Only pair devices you control. Revoke lost or untrusted devices in Mac Settings.
- Review file and terminal approvals. Do not use sensitive production folders for experiments.
- Keep the host, model server, and dependencies updated.
- Do not post credentials, pairing QR codes, private prompts, or exploitable sensitive details in public issues.

If you find a vulnerability, use GitHub's private vulnerability reporting when available. Otherwise contact the repository maintainer privately before publishing details. This preview has no guaranteed security response SLA.
