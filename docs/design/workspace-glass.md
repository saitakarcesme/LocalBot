# Workspace glass direction

Keep the real PTY, WebKit browser, file editing, Git review and independent side chat. Replace the opaque full-height block and stacked Workspace/title/tab bars with an inset rounded native glass surface matching the navigation sidebar. A single compact bottom strip owns tabs, add and close; only essential content controls remain above the content. Project rows become avatar + title at the same height as Recents.

Mount only the selected pane; retain session/draft state independently. Avoid animating expensive text reflow, cache message measurements, and use AppKit cursor regions for resizing. Activity becomes a chronological execution feed with concise event labels, bounded output previews and expandable full output. No invented reasoning: only provider public summaries and recorded tool events.

Verify tab state preservation, browser/terminal interaction, scrolling, fullscreen geometry and repeated panel transitions. Compare interaction profiling before and after; idle CPU alone is not a fluidity test.
